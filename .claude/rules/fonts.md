# Шрифты направления

Ponomar (заголовки), Forum (капитель), Golos Text (текст и знак рубля) — через `next/font/local` в `src/styles/fonts.ts`, модуль импортируется в layout.
- Имя семейства — через `declarations: [{ prop: 'font-family', … }]`: иначе next/font назвал бы семейство по имени константы, и `--font-*` разошлись бы с артбордом, а они сверяются с ним побайтово.
- `adjustFontFallback: false`: свои запасные начертания next/font здесь не нужны; у `next/font/local` флаг действует — лишних `@font-face` в CSS нет (на сайте студии он не действует только у `next/font/google`).
- Preload включен: направление одно, все три шрифта нужны на каждой странице, next отдает их заголовком `Link`.
- Константы в `fonts.ts` никто не импортирует (модуль подключается ради `@font-face`), но `export` снимать нельзя: next/font требует `const` на уровне модуля, а неиспользуемая константа без `export` дает три предупреждения `no-unused-vars`.

**Сабсеты.** `yarn subset:fonts` (`scripts/subset-fonts.mts`) качает исходники из `google/fonts` по закрепленному коммиту (кеш в `node_modules/.cache`), режет до `GLYPHS` из `scripts/subset-glyphs.mts`, кладет в `src/styles/fonts/` рядом с OFL. Вывод детерминированный: `tests/unit/font-files.test.ts` дважды запускает скрипт и сравнивает побайтово с репозиторием → правка скрипта без пересборки файлов тоже роняет тест. Хинтинг выброшен, как у самого Google Fonts для всех систем, кроме Windows. Из OpenType-фич оставлены те, что браузер включает сам, плюс `tnum` для `tabular-nums`: стилистические наборы Ponomar весили 16 КБ, а отрисовка по умолчанию с урезанным набором совпадает попиксельно. Итого 61 КБ на три шрифта.

**Лицензии.** Рядом с каждым файлом — его OFL. Лицензия Forum резервирует имя «Forum», а сабсет по OFL-FAQ 2.6–2.8 — модифицированная версия (набор знаков урезан, хинтинг снят) и носить это имя не может. Поэтому скрипт переписывает в его таблице `name` семейство, полное имя, уникальный идентификатор и PostScript-имя на «Kaup Caps» (`scripts/sfnt-name.mts`; harfbuzz в сборке `subset-font` этого не умеет); копирайт и версия остаются. Имя семейства в CSS по-прежнему 'Forum': оно сверяется с артбордом, а запрет FAQ касается имени в меню шрифтов. Отсюда же `FILE_FAMILY` в e2e: Chrome сообщает имя из файла, для Forum это «Kaup Caps». Сторожит `tests/unit/font-license.test.ts`: зарезервированные имена берутся из самих файлов OFL, в таблице `name` сабсета их не должно быть нигде, кроме копирайта и лицензии.

**Покрытие знаков.** `tests/unit/font-subset.test.ts` собирает все знаки текстов репозитория через AST TypeScript: строки, шаблоны, JSX-текст с раскрытыми сущностями (`&nbsp;` в AST — шесть латинских букв, а не неразрывный пробел), плюс `content` в стилях. Знак вне `GLYPHS` роняет тест: он отрисовался бы запасной гарнитурой. Тест сверяет тексты с `GLYPHS`, а не с файлами, а в самих шрифтах есть пробелы: в Ponomar нет `№` и `₽`, в Forum — `Ѐ` и `₽`, в Golos Text — `Ѐ Ѝ ѐ ѝ` (их нет и в исходниках). Поэтому знак рубля набирается Golos Text (`Price`), а `№` в заголовке Ponomar уйдет в запасную гарнитуру — поймает только e2e ниже и только если такой текст стоит на проверяемой странице. Знаки контента CMS — тема `content-import.md`.

**Что рисуется на самом деле.** `tests/e2e/fonts.spec.ts` берет через CDP `getPlatformFontsForNode` шрифты, которыми Chrome набрал глифы каждого видимого узла. Вычисленный `font-family` для этого бесполезен: одинаков и при незагруженном шрифте, и при знаке, выпавшем из сабсета. CDP отдает шрифты узла вместе с вложенными строчными элементами → узлу разрешены первые семейства его собственного текста и вложенного (у цены число — Ponomar, знак рубля — Golos Text).

Запасные начертания (`'<Семейство> Metric Fallback'` в `tokens.scss`), их подгонка и три проверки — тема `fallback-fonts.md`.
